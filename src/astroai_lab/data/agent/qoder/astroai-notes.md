# Qoder CLI on CANFAR

1. Install onto scratch: `astroai agent install qoder`
2. The binary on PATH is `qodercli` (install id is `qoder`).
3. Authenticate per Qoder docs: https://qoder.ai — run `qodercli` after install.
4. Binary lives under `$ASTROAI_LAB_BIN_DIR` (scratch); credentials stay on `$HOME` (/arc/home).
