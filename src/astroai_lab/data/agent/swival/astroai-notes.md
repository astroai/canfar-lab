# Swival on CANFAR

1. Install onto scratch: `astroai agent install swival`
2. Optional OpenRouter key: https://openrouter.ai/keys — `export OPENROUTER_API_KEY=sk-or-v1-...`
3. Run `swival` and follow upstream setup (https://pypi.org/project/swival/).
4. Binary lives under `$ASTROAI_LAB_BIN_DIR` (scratch); config stays on `$HOME` (/arc/home).
