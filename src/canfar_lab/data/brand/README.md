# AstroAI brand assets

`astroai-logo.png` is the GitHub organization avatar for
[astroai](https://github.com/astroai) (`avatars.githubusercontent.com/u/25205437`).

Used by AstroAI Panel CLI (`canfar lab studio review doctor`) and docs. Re-fetch with:

```bash
curl -fsSL -o src/canfar_lab/data/brand/astroai-logo.png \
  'https://avatars.githubusercontent.com/u/25205437?s=256'
```

## CANFAR

`canfar-logo.png` is the CANFAR mark from
[opencadc/canfar](https://github.com/opencadc/canfar) (`docs/static/logo.png`)
on a dark rounded tile (128 px), so its white strokes read on light pages. The
Studio image uses it for the tab strip; the dsh brand plugin embeds the same
mark.
