# Freebuff on CANFAR

1. Install onto scratch: `astroai agent install freebuff`
2. Optional OpenRouter key: https://openrouter.ai/keys — `export OPENROUTER_API_KEY=sk-or-v1-...`
3. Run `freebuff` and follow upstream provider setup (https://www.npmjs.com/package/freebuff).
4. Binary lives under `$ASTROAI_LAB_BIN_DIR` (scratch); agent state stays on `$HOME` (/arc/home).
