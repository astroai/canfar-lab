# ZCode CLI on CANFAR

1. Install onto scratch: `astroai agent install zcode`
2. npm package is `zcode-app-cli`; run `zcode` after install.
3. ZCode creates its own config on first launch — see https://github.com/kingsword09/zcode-cli.
4. Binary lives under `$ASTROAI_LAB_BIN_DIR` (scratch); runtime config stays on `$HOME` (/arc/home).
